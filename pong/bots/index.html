Bot function

Your function signature should match:

function(paddle, ball, field, lineDrawer) {}

The return value, if any, is unused. The four parameters contain the methods described below.

Paddle

move(v)
Moves the paddle up if v is less than 0, down if v is greater than 0, and not at all if v is 0.
getX()
Returns the x coordinate of the center of the paddle.
getY()
Returns the y coordinate of the center of the paddle.

Ball

getX()
Returns the x coordinate of the center of the ball.
getY()
Returns the y coordinate of the center of the ball.
getDX()
Returns the speed of the ball along the x-axis.
getDY()
Returns the speed of the ball along the y-axis.

Field

getWidth()
Returns the width of the field.
getHeight()
Returns the height of the field.

Line Drawer

add(line)
Adds line to be drawn next frame.

Line

constructor(x1, y1, x2, y2)
Represents a line segment from the points (x1, y1) and (x2, y2).
